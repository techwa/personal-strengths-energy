# 个人优势与能量来源框架 v1.0

> 本 Skill 的分析框架。扫描、归类、命名、判别一律以本文件为准。

## 设计原则

1. **切分刀**：优势按"行为作用的对象"切成五维（信息观念 / 任务资源 / 关系 / 他人认知行为 / 自己）；能量按"能量进入的界面"切成五维（内在需要 / 做事过程 / 关系他人 / 意义超越 / 身心环境）。同一维度内的项互斥，靠判别规则守边界。
2. **两本账原则**：优势框架记"擅长什么"，能量框架记"什么供能"——同一件事可以在两边各记一笔（擅长修复 ≠ 修复给你充电），两边都记才是完整画像。因此两框架之间允许主题呼应，框架**内部**必须互斥。
3. **MECE 的诚实边界**：人的心理不真正 MECE。本框架的 MECE 是工程目标——扫描不遗漏、归类不打架——不是心理学断言。判别规则解决 95% 的归类争议，剩下的疑难以"证据落在哪边更多"裁决。
4. 不与任何现有测评一一对应；条目命名一律用大白话。

# 一、个人优势框架（5 维 · 25 项）

## ① 思维优势（作用于信息与观念）

| 项 | 一句话定义 | 判别（与最近邻区分） |
|---|---|---|
| 洞察 | 能直接看出事物的本质和别人没注意到的模式 | vs 分析：结论是"一眼看出来的"还是"一步步拆出来的"？洞察是跳跃综合，分析是过程分解 |
| 分析 | 能把复杂问题逐步拆解、讲清证据和因果 | vs 判断：产出是"搞明白了"还是"做了决定"？分析求理解，判断求取舍 |
| 判断 | 在信息不全时能权衡取舍、定下方向 | vs 分析（同上）；vs 审慎式犹豫：判断的标志是**敢定**，不是想得久 |
| 创想 | 不停生成新点子，擅长把不相干的东西联起来 | vs 洞察：创想是发散造新，洞察是收敛看清已有 |
| 学习 | 上手陌生领域快，吸收新知识的速度和胃口都大 | vs 洞察：学习是吸收已有的，洞察是产出新理解；vs 能量侧"探索"：学习是能力（学得快），探索是燃料（新奇让我爽）——两本账 |
| 前瞻 | 能构想未来的图景和走向，并被它牵引 | vs 创想：兴奋点在"未来会怎样"还是"这个点子本身"？ |

## ② 成事优势（作用于任务与资源）

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 成事 | 能把想法变成行动并推到完成——从"让它开始"到"把它做完" | 报告时可标注偏向（偏启动 / 偏收尾 / 全程），但不作为两项分别计分；vs 坚毅：成事是顺境下的完成力，坚毅是逆境中的不放弃 |
| 专注 | 定了目标就能自动屏蔽干扰、长时间锁定 | vs 自律：屏蔽干扰是"自然发生"还是"靠意志硬撑"？专注不费力，自律费力 |
| 组织 | 能让复杂变得可管理：调度多条线的人和资源，或建立起结构与秩序 | 报告时可标注偏向（偏临场调度 / 偏建立制度）；vs 成事：组织解决"怎么安排"，成事解决"能不能做完" |
| 精进 | 见不得"还行"，总想把好的打磨到卓越 | vs 排难：对象是"好的（80→95）"还是"坏的（0→能用）"？ |
| 排难 | 被坏掉的东西吸引，擅长也乐于修复 | vs 精进（同上）；注意与能量侧"解决"两本账：擅长修 ≠ 修给你充电 |

## ③ 联结优势（作用于关系本身；双向、以关系为目的）

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 读人 | 能读懂具体的人——此刻的情绪，或一贯的特质——并据此调整对待方式 | 报告时可标注偏向（偏读情绪 / 偏读特质）；vs 洞察：对象限定为"具体的人"（维度切分使然）；vs 培养：停在"读懂了"还是走到了"带人"？ |
| 培养 | 看见他人潜力后会真的投入去帮对方成长 | vs 读人：读人是看见，培养是投资 |
| 深交 | 擅长与少数人建立深度信任关系 | vs 破冰：主场在"关系的深处"还是"关系的开端"？ |
| 融合 | 能把一群人拢在一起：促成共识、化解摩擦、不落下任何人 | vs 培养：作用于"群体的整体状态"还是"某个人的成长"？ |
| 破冰 | 与陌生人快速建立连接、赢得好感 | vs 深交（同上）；vs 感染：破冰的目标是建立关系，感染的目标是改变对方状态 |

## ④ 影响优势（作用于他人的认知与行为；单向、以改变为目的）

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 表达 | 能把复杂的东西讲清楚、讲生动 | vs 说服：成功标准是"对方听懂了"还是"对方同意并行动了"？ |
| 说服 | 能让人接受你的观点并愿意跟着做 | vs 表达（同上）；vs 主导：走的是"认同路径"还是"权威路径"？ |
| 主导 | 关键时刻天然接管局面、敢拍板担责 | vs 说服（同上）；主导不需要对方心服，需要局面动起来 |
| 感染 | 用自己的状态和情绪天然带动周围人 | vs 说服：靠的是"论证"还是"状态本身"？感染不讲道理 |

## ⑤ 自持优势（作用于自己）

> **扫描提示（重要）**：本维度极少在工作记录里留下直接行为证据，容易系统性扫空。请专门在这些痕迹里找：坚持了很久没放弃的事（哪怕没成）、明知难受还是做了的事、主动戒掉或克制的习惯、事后复盘自己而非归咎他人的记录、在压力下仍守住的底线、拒绝过的诱人机会。仍不足时，本维度以 Phase 2 的追问为主要证据来源，并在报告中标注。

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 自律 | 能日常自我约束：抵住诱惑、守住节律 | vs 坚毅：敌人是"诱惑"还是"挫折"？vs 专注：费力与否（见专注） |
| 坚毅 | 长期目标下遇挫不弃、扛得住反复失败 | vs 自律（同上）；vs 成事：成事管顺境完成，坚毅管逆境坚持 |
| 勇气 | 面对风险、冲突或不适，仍然选择行动 | vs 坚毅：勇气是"那一下敢不敢"，坚毅是"长期撑不撑得住" |
| 真实 | 表里如一，敢按真实的自己行事和表态 | vs 勇气：内核是"一致"不是"敢"——说真话对真实的人不需要勇气 |
| 自省 | 能觉察自己的状态、情绪与行为模式 | vs 洞察：对象是自己而非外部（维度切分使然） |

# 二、个人能量来源框架（5 维 · 24 项）

## ① 内在需要（心理需求被满足时充电）

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 自主 | "这是我自己选的、我说了算"时充电 | vs 环境侧"秩序与可预测"：自主关心"谁决定"，秩序关心"是否可预测"；vs 做自己：自主管"谁决定做什么"，做自己管"我能不能不演" |
| 胜任 | 明显感到"我做得好"时充电 | vs 成长：满足来自"我水平高"还是"我在变强"？vs 认可：没人夸但自己知道做得好，够不够？够=胜任，不够=认可 |
| 成长 | 感到能力边界在扩大时充电 | vs 胜任（同上）；vs 盼头：成长是"当下在变强"，盼头是"前方有期待" |
| 做自己 | 不用伪装、能以真实面貌出现时充电（戴面具则持续耗电） | vs 自主（同上）；vs 意义侧"意义感"：意义感关乎"事"值不值，做自己关乎"我"能不能以本色出现；与优势侧"真实"两本账：有真实的品质 ≠ 环境允许你做自己 |
| 盼头 | 前方有值得期待的事时充电（没盼头的日子明显发灰） | vs 成长（同上）；与优势侧"前瞻"两本账：擅长构想未来 ≠ 需要盼头供能 |

## ② 做事过程（任务本身的特性在供能）

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 创造 | 从无到有做出一个东西的过程让你充电 | vs 留痕：爽点在"做的过程"还是"做完看到改变"？ |
| 探索 | 接触新事物、有所发现时充电 | vs 优势侧"学习"两本账；vs 高质量碰撞：新奇经由"事物"还是经由"人"？ |
| 解决 | 把坏的修好、把乱的理顺时充电 | vs 创造：对象是"从无到有"还是"从坏到好"？ |
| 留痕 | 做完后看到有东西或有人因你而不一样时充电 | vs 创造（同上）；留痕在乎的是事后可见的改变 |
| 沉浸 | 深度投入到忘记时间的状态本身让你充电 | vs 探索：不依赖内容新旧，重复的事做进心流也充电；vs 胜任：沉浸不要求做得好——菜鸟也能沉浸；胜任需要"我确实做得不错"这个判断 |
| 胜负 | 有对手、有标尺、能赢时充电 | vs 胜任：没有对手还爽吗？爽=胜任（绝对水平），不爽=胜负（相对比较） |

## ③ 关系与他人

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 深度连接 | 与人产生真实、走心的连接时充电 | vs 归属：一对一的深，还是群体的"我属于这里"？ |
| 助人 | 具体的人因你的帮助受益时充电 | vs 意义侧"贡献感"：需要看到具体的人并有互动吗？需要=助人，不需要=贡献感 |
| 认可 | 被他人看见、欣赏、称赞时充电 | vs 胜任（见胜任）；注意进一步辨别认可背后是什么（见附注） |
| 归属 | 感到"我是这个群体的一员"时充电 | vs 深度连接：把群体换成任意一个具体的人单独相处，还充电吗？充=深度连接，不充=归属（要的是"在场的集体"） |
| 碰撞 | 与厉害的、有想法的人交流切磋时充电 | vs 探索：经由人；vs 认可：碰撞不需要被夸，需要被激发 |

## ④ 意义与超越

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 意义感 | 感到做的事值得——符合自己的信念，或连着比自己更大的东西——时充电 | vs 贡献感：意义感不要求对谁有益，"这事值得"本身就够；vs 做自己：意义感关乎"事"值不值，做自己关乎"我"能不能以本色出现 |
| 贡献感 | 感到所做之事对他人或世界有益时充电 | vs 助人（见助人）；vs 意义感：贡献感必须指向"有益于外部"，意义感不必 |
| 审美与惊奇 | 美的时刻、巧合与同构的发现让你充电 | 独立项：不依赖成就、关系或意义，纯粹"这一刻真美/真妙" |

## ⑤ 身心与环境

| 项 | 一句话定义 | 判别 |
|---|---|---|
| 身体激活 | 身体先动起来（运动、走路）后整个人被点亮 | 生理路径，不经由心理需求 |
| 空间与自然 | 换个环境、身处自然或美的场所时充电 | vs 审美与惊奇：这里是"环境作为容器"，那里是"对象作为体验" |
| 刺激适配 | 刺激量对口时充电：有人要安静独处，有人要热闹人群 | 个体参数项——扫描时记录用户偏哪头 |
| 秩序与可预测 | 环境有序、节奏可预期时充电 | vs 自主（见自主） |
| 恢复与节律 | 睡眠、留白、张弛有度本身在供能 | 最物理的一项，常被高估的意志力掩盖 |

**耗能不单独建框架**：每一项的"被剥夺态"即耗能（自主被剥夺=事事须审批……），另加两个通用耗能项——**优势被迫闲置**（有力使不出）与**被迫长期使用弱项**。

**附注·认可的进一步辨别**：用户说"被认可很开心"时不要停在表层，追问认可背后激活的是什么——胜任确认（证明我确实行）/ 影响确认（我的东西真有用）/ 连接确认（我在意夸我的这个人）/ 机会确认（认可意味着门在打开）。落到哪项就记哪项，"认可"只在都不是时才独立记账。
