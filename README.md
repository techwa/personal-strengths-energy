# personal-strengths-energy 
我的优势与能量来源

**Personal Strengths & Energy** — 一个帮助人们从真实经历中发现个人优势与能量来源的 Agent Skill。（v1.0）

> 从真实经历里，发现你反复做得好的事、真正给你能量的东西，以及什么情况下你最容易进入状态。

## 为什么做这个 Skill

无论你是想认真做一次自我探索，想化解工作和生活中反复出现的焦虑与困惑，还是想找到值得长期投入、能产生"人生复利"的事——**了解自己的优势与能量来源，都是绕不开的一步**：

- **自我探索**需要一个可靠的起点。比起抽象的"我是什么类型的人"，"我反复做得好什么、什么真的给我能量"是更接近真实自己的答案；
- **很多焦虑和困惑**，本质上是处境与自己的优势和能量不匹配，却被误读成了"我不行"。看清这一点，问题会从"我怎么了"变成"哪里错位了"——后者可解得多；
- **人生复利**来自把时间持续投入在"既擅长、又能充电"的事情上。优势保证做得好，能量保证做得久，二者的交集才是值得长期押注的方向。

基于此，还有一个基本假设：很多时候我们向他人或 AI 求助，以为需要从外部获得解决方案。但实际上，解决方案往往源于我们自身：我们可能本身就具备解决问题的优势，或者当前的困扰恰恰是因为处境与自己的优势和能量来源不匹配。

这个 Skill 让 AI 做两件事：

1. **辅助自我了解**：发现你反复表现出的显性优势、容易被低估的隐性优势、真正的能量来源，以及最容易进入高能状态的激活条件。
2. **优势视角解决问题**：当你遇到工作或生活困扰时，从"你已经拥有什么"出发分析问题，而不是只盯着"你缺什么"。

它不是人格测验，不输出类型标签或分数。它的目标是基于你的真实经历，形成一个**有证据、可修正、能用于现实选择的个人模型**。

## 核心设计

**Memory supplies the evidence. Questions only calibrate it.**（记忆出证据，提问做校验。）

- **证据优先，记忆为主**：结论必须来自具体事件与重复出现的行为模式，主要证据取自长期记忆而非当场问答——不把用户刚说的话复述回去当"洞察"；过去 AI 的评价只能作线索，不能作证据；
- **反彩虹屁**：结论强度必须匹配证据强度，禁止无证据夸奖，证据不足就标注"待验证"；
- **区分擅长与有能量**：做得好、喜欢做、做了以后能量上升——三者可能完全不同；
- **解决问题走干预阶梯**：小实验 → 协商调整 → 大决策，不跳级；重大人生决策只提供能量结构作参照，不替用户决定；
- **高能条件不是公式**：输出"核心触发器 / 放大器 / 最低可行组合"的层次地图，而不是"必须全部满足"的神仙环境；
- **隐私边界内建**：读取任何记忆前必须先问排除范围；能读 ≠ 该展示；渐进式检索，不穷举人生；覆盖范围对用户透明，不夸大"我看完了你的一切"。

## 工作流

```
Phase 0  启动与模式判断    Mode A 了解自己 / Mode B 优势视角解决问题
Phase 1  说明与授权确认    记忆边界 + 数据量与准确性说明
Phase 2  记忆回溯          渐进式检索 + 覆盖透明协议
Phase 3  个性化追问        最多 7 问；证据不足/用户不配合有明确降级方案
Phase 4  生成报告          两层结构：30 秒核心地图 + 深度解释
```

## 安装与使用

**Claude.ai / Claude App**：在设置中的 Skills（能力）里上传打包好的 `.skill` 文件；或将整个文件夹放入支持 Agent Skills 的环境。

**Claude Code**：将文件夹复制到 `~/.claude/skills/personal-strengths-energy/`。

**其他 Agent 框架**：本 Skill 只依赖 Markdown 指令。长期记忆读取为可选能力——宿主不支持时，Skill 会自动降级为基于当前对话与用户提供的经历，且明确禁止假装读取过记忆。

触发方式：直接对 AI 说——

- "分析一下我的优势" / "我真正擅长什么？"
- "什么东西最能给我充电？" / "为什么有些事情我做起来特别投入？"
- "我最近工作很没劲，能不能从我的优势角度帮我看看？"

## 隐私说明

- 只有在你明确授权后才读取长期记忆或个人上下文，并严格尊重你排除的内容；
- 本 Skill 不做精神疾病诊断、人格障碍判断或临床评估。

## 理论背景

框架灵感来自优势心理学、VIA character strengths、CliftonStrengths 的优势视角、自我决定理论（Self-Determination Theory）、心流（Flow）与 Person–Environment Fit。本 Skill 不等同于、也不复刻任何商业测评，不输出未经正式测量的量表结果。
